Source cohort: main_experiment_cohort.mat
Design: 10 fixed High-complexity environments, one pre-specified seed per environment.
Settings: baseline plus 0.5x and 1.5x one-at-a-time perturbations of each reported weight.
Base weights: w_energy=1, w_time=0.5, w_climb=2, w_risk=10, lambda_penalty=100.
RA-ALA budget: popSize=40, maxIter=80.
The auxiliary search riskWeight remains fixed at 15; it is not treated as a reported J weight.

Implementation rule:
- RA-ALA and ST-EA* are re-optimized under every weight setting.
- Energy-A*, Informed-RRT*, and Greedy paths are generated once per environment and rescored,
  because their implemented path-generation objectives do not use the reported composite-cost weights.
- Raw J values are not compared across different settings because each setting defines a different objective.
  Interpretation uses within-setting algorithm ranks, feasibility, and physical outcome components.
